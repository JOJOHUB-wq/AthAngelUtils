# AthAgnelUtils v0.1.0 — Fabric 26.2, client-only

Автор: AtheriumDev (https://atheriumdev.com)

## v0.1.19 — підсумок цієї ітерації

- **Автокапча: нейронку донавчено на справжньому шрифті.** Стара модель знала лише Arial-подібні
  цифри й плутала нову капчу (62% на захоплених реальних цифрах). Нова модель, натренована на
  реальних зразках обох полярностей + аугментація, дає **44/45 (≈98%)** на тій самій вибірці
  (виміряно офлайн-бенчем `tools/ocrbench`, який ганяє справжній код `CaptchaOcr`/`MlpOcr`).
- **Полярність шрифту:** `normalize()` тепер авто-визначає, чи цифри світлі на темному, чи темні на
  світлому — стара й нова капчі читаються однаково.
- **Реконект:** після успішного входу лічильник спроб скидається (не тягнеться роздутий бек-оф з
  минулої серії); логіка бек-офу/паузи/БАНу винесена в чистий `ReconnectPolicy` і покрита
  юніт-тестом (`PolicyTest`, усі pass).
- **Фікс бага кольорових кодів:** `ChatText.norm` спершу прибирав `§.`, що зʼїдало `§#` у hex-кольорах
  і лишало сміття — через це ламався пошук ключових слів (включно з тригером капчі). Тепер порядок
  правильний.
- **Розвантаження репозиторію:** випадково закомічений 49 МБ дамп сесії `athagnelutils.json` винесено
  з git (лишився локально, додано в `.gitignore`).

Офлайн-валідація (без Minecraft): `tools/ocrbench/run.sh batch` — компілює справжні `CaptchaOcr`/
`MlpOcr` і женеться по мічених реальних цифрах з `capwork/`. Потребує лише JDK (ботстрапиться
sparse-клоном) і не чіпає клієнт.

## Що вміє v1

- **Автореконект**: після кіку/втрати зʼєднання сам перепідключається до angelgrief
  (затримка `reconnectDelaySeconds`, ручний вихід через Esc — не чіпає).
- **Автологін**: бачить прохання авторизації в чаті → відправляє `/l 0707`
  (пароль у `config/athagnelutils.json`, команда `/agnel pass <новий>`).
- **Капча-помічник**: на `AngelFilter » Введите капчу` — тост у чат + стоп майнера.
  Повний авто-OCR буде у v2 (треба 5–10 зразків карти капчі).
- **Авто-хаб**: після заходу тискає ПКМ по компасу і клікає слот `Анархія + 1.21`
  (ключові слова в конфігу `anarchyKeywords`).
- **Screen-логер**: кожне контейнер-меню пише в `config/athagnelutils-screens.log`
  (назва + слоти) — пришли мені цей файл після заходу в хаб/скупщика,
  щоб я точно налаштував слоти.
- **Майнер-каркас** (ВИМКНЕНИЙ за замовчуванням): гейт по CapsLock **або** клавіша `G`,
  `/warp mine` при вмиканні, guard кірки (`minPickaxeDurability`), без флая.

## Команди (клієнтські)

- `/agnel status` — стан модулів
- `/agnel hub` — вручну запустити компас → анархія
- `/agnel mine` — тогл майнера (= клавіша `G`)
- `/agnel login` — відправити `/l` зараз
- `/agnel reload` — перечитати конфіг
- `/agnel pass <пароль>` — змінити пароль

## Увімкнення майнера (після тесту бази!)

1. `config/athagnelutils.json` → `"minerEnabled": true`
2. У грі: увімкни CapsLock (горить лампочка) **або** тисни `G` → сам зробить `/warp mine`
3. Кірка в руку. Якщо міцності менше `minPickaxeDurability` — стоп + попередження.
4. Флай вимкни сам: у флаї реси не підбираються (перевірено по логах сервера).
